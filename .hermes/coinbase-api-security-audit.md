# Coinbase API Security & Authentication Audit

## Three-Tiered Key Structure

### Client API Key
- Purpose: Client-side app requests (safe for frontend)
- Location: RPC endpoint URL prefix (`https://api.developer.coinbase.com/rpc/v1/base/<CLIENT-API-KEY>`)
- Authentication: JSON-RPC headers only

### Secret API Key  
- Purpose: Server-to-server REST communication, JWT generation
- **NEVER** expose in client code or browser
- Location: Generated at https://portal.cdp.coinbase.com/projects/api-keys → Secret API Keys tab
- Configuration: IP allowlist (recommended), Ed25519 signature algorithm (recommended)
- Environment variables required:
  - `KEY_ID="your-key-id"`
  - `KEY_SECRET="your-s...key=="`
- **Output**: Bearer Token (JWT) valid for 2 minutes

### Wallet Secret
- Purpose: Sensitive wallet write operations (EVM/Solana sign transactions, account actions)
- Security level: Password-level security (TEE-generated by CDP)
- Location: https://portal.cdp.coinbase.com/wallets/non-custodial/security → Generate button
- **NEVER** share or expose in client code
- Environment variable required: `WALLET_SECRET="your-w...cret"`
- **Output**: Wallet Authentication JWT valid for 1 minute

## Security Best Practices

### Key Management
- ✅ **Secret API Key**: Store ONLY in environment variables or secure vault
- ✅ **Wallet Secret**: Treat like password, never share or expose client-side
- ✅ **Client API Key**: Safe for browser/mobile JSON-RPC requests only

### Certificate & Clock Validation
- **Bearer Tokens** valid 2 minutes - verify machine clock accuracy
- **Wallet Auth JWTs** valid 1 minute - regenerate before expiration
- Time drift causes authentication failures; use synchronized system time

## Rate Limiting Strategy

```python
# Exponential backoff pattern for rate limit handling
import time
from functools import wraps

def with_rate_limit(func):
    """Handle Coinbase API rate limits with exponential backoff."""
    @wraps(func)
    def wrapper(*args, **kwargs):
        max_attempts = 5
        base_delay = 1.0
        
        for attempt in range(max_attempts):
            try:
                return func(*args, **kwargs)
            except Exception as e:
                if 'rate limit' in str(e).lower() or '429' in str(e):
                    delay = min(base_delay * (2 ** attempt), 60)
                    print(f"Rate limited. Retrying in {delay}s...")
                    time.sleep(delay)
                else:
                    raise
        return func(*args, **kwargs)
    return wrapper
```

## Multi-Service Fleet Deployment Pattern

### Circuit Breaker with Key Rotation (2-min Bearer, 1-min Wallet)

```python
import time
import os
from dataclasses import dataclass
from typing import Optional
from datetime import datetime

@dataclass
class TokenState:
    """Track JWT state for automatic rotation."""
    bearer_token: str
    wallet_auth_token: str
    last_bearer_refresh: float
    last_wallet_refresh: float
    bearer_ttl_seconds: int = 110  # Refresh before 2-min expiry  
    wallet_ttl_seconds: int = 55   # Refresh before 1-min expiry

class CoinbaseTokenManager:
    """Manage JWT tokens with automatic rotation for multi-service fleet."""
    
    def __init__(self, bearer_token_id: str, bearer_secret: str, 
                 wallet_secret: str):
        self.bearer_token_id = bearer_token_id
        self.bearer_secret = bearer_secret
        self.wallet_secret = wallet_secret
        self.state = TokenState(
            bearer_token="",
            wallet_auth_token="",
            last_bearer_refresh=0,
            last_wallet_refresh=0
        )
    
    def refresh_tokens(self):
        """Refresh both JWT tokens with CDP SDK."""
        from cdp.auth.utils.jwt import generate_jwt, JwtOptions
        
        # Bearer token (Secret API Key → 2 min TTL)
        self.state.bearer_token = generate_jwt(JwtOptions(
            api_key_id=self.bearer_token_id,
            api_key_secret=self.bearer_secret,
            request_method="GET",
            request_host="api.cdp.coinbase.com",
            request_path="/platform/v1/health",  # Health check path
            expires_in=120
        ))
        
        # Wallet Auth token (Secret API Key + Wallet Secret → 1 min TTL)
        self.state.wallet_auth_token = generate_jwt(JwtOptions(
            api_key_id=self.bearer_token_id,
            api_key_secret=self.bearer_secret,
            request_method="POST",
            request_host="api.cdp.coinbase.com", 
            request_path="/platform/v2/evm/accounts/<account>/sign/transaction",
            expires_in=60
        ))
        
        self.state.last_bearer_refresh = time.time()
        self.state.last_wallet_refresh = time.time()
    
    def get_bearer_token(self) -> str:
        """Get bearer token, refresh if expired."""
        now = time.time()
        elapsed = now - self.state.last_bearer_refresh
        
        if elapsed >= self.state.bearer_ttl_seconds:
            self.refresh_tokens()
        
        return self.state.bearer_token
    
    def get_wallet_auth_token(self) -> str:
        """Get wallet auth token, refresh if expired."""
        now = time.time()
        elapsed = now - self.state.last_wallet_refresh
        
        if elapsed >= self.state.wallet_ttl_seconds:
            self.refresh_tokens()
        
        return self.state.wallet_auth_token
```

## Security Audit Checklist for Implementation

- [ ] **Key Storage**: All secrets in environment variables only (never hardcoded)
- [ ] **IP Allowlist**: Secret API Key configured with IP restrictions if possible
- [ ] **Signature Algorithm**: Ed25519 used for EdDSA signing
- [ ] **Token Rotation**: Automatic JWT refresh before expiration (110s for 2-min tokens, 55s for 1-min tokens)
- [ ] **Circuit Breaker**: Protection against rate limits with exponential backoff
- [ ] **Webhook Verification**: Signature validation for incoming events
- [ ] **Error Handling**: Graceful failure and logging (no secrets in error messages)
- [ ] **Health Checks**: `/health` endpoint monitors token state and API connectivity
