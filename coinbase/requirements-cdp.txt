# Coinbase Developer Platform (CDP) Integration Requirements

## Core Dependencies

```
cdp-cli>=0.1.0     # Coinbase Developer Platform CLI tool
requests>=2.31.0   # HTTP library for API calls
python-dotenv>=1.0.0  # Environment variable management
```

## Development Dependencies

```
pytest>=7.4.0      # Testing framework
pytest-cov>=4.1.0  # Coverage reporting
black>=23.12.0     # Code formatting
mypy>=1.8.0        # Type checking
isort>=5.12.0      # Import sorting
```

## Install Command

```bash
pip install -r requirements.txt
```

## Alternative: Full Development Install

```bash
pip install -r requirements-dev.txt  # If you create this file
```

## CDP CLI Installation

After installing Python dependencies, you also need the CDP CLI:

```bash
pip install cdp-cli
cdp init --name my-wallet --testnet
cdp login
```

See examples in `coinbase/cdp/examples/production_setup.md` for complete setup instructions.
