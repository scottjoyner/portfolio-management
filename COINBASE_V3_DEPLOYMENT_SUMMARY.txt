🔑 AUTHENTICATION APPROACH
================================================================================

How it works:
  1. You provide cdp_api_key.json (with private key)
  2. Setup script stores it securely via libsecret
  3. Coinbase CLI loads the key and generates JWT tokens
  4. CLI signs requests with ES256 (ECDSA)
  5. Python connector calls CLI, gets JSON back

Security:
  ✅ Private key never exposed in code
  ✅ Libsecret: secure credential storage
  ✅ Each request: new JWT token (3-min expiry)
  ✅ CLI handles all cryptography
